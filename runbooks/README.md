# Runbooks

On-demand instructions for Claude Code. `CLAUDE.md` holds only the hard rules and a routing table; it
points here, and Claude reads the matching runbook before starting a task. Not published (outside `docs/`).

| Runbook | Read before |
|---|---|
| `talks.md` | any 5, 10, or 30-minute talk: outline template, script workflow, formatting standards, image template, summary.md |
| `hiyas.md` | an Espirituwal na Hiyas conductor script (Tanong 1, top-10 gems, handang sagot, closing) |
| `cbs.md` | a CBS conductor script |
| `watchtower.md` | a Watchtower answer script (MANDATORY answer format) |
| `field-ministry.md` | a field ministry demonstration or arrangement script |
| `coaching.md` | a coaching request ("coach me", "improve intro") and the struggle → Aralin mapping |
| `reference-library.md` | finding a stored book/PDF, an NWT page, a workbook week, or a stored article — and when adding one |
| `publishing.md` | nav entries, GitHub Pages, MkDocs Material features, Notion `/10minute` |

**Rules for this folder**
- If a runbook and `CLAUDE.md` disagree, `CLAUDE.md` wins — fix the runbook.
- New procedures, templates and lookup rows go into the matching runbook, not into `CLAUDE.md`.
- Never put full copyrighted text here (repo is public); that stays in git-ignored `reference/books/` and `reference/articles/`.
